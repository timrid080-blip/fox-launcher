# Fox Launcher 3.1.0 — PC Edition

Независимый Minecraft Java Launcher для Windows 10/11 x64. Проект использует Electron и Supabase. Не является продуктом Mojang или Microsoft.

## Статус проекта

- Версия 3.1.0 ориентирована на Windows-ПК. Android-клиент и сборка APK временно исключены; мобильную версию планируем отдельно для 4.0/5.0. См. `ANDROID-STATUS-RU.md`.

- Исходники лаунчера и конфигурация сборки находятся в этом репозитории.
- Проверка обновлений использует GitHub Releases: обычный push в `main` сам по себе не публикует релиз.
- Реальные платежи по умолчанию отключены.
- Изменения базы данных нужно применять последовательными миграциями к существующей базе; не запускайте полный `supabase.sql` поверх рабочей базы.

## Документы

- `BUILD-AND-HANDOFF-RU.md` — сборка проекта и выпуск обновлений.
- `RELEASE-1.5-RU.md` — прежняя инструкция по установке и SQL; часть сведений может относиться к более ранним версиям.
- `migrate-*.sql` — миграции базы. Перед применением сделайте резервную копию и проверьте порядок миграций.

## Для разработчиков

1. Установите совместимую версию Node.js.
2. Выполните `npm ci`.
3. Запустите тесты командой `npm test`.
4. Для локального запуска используйте скрипты из `package.json`.
5. Для публикации обновления создайте версионный тег `vX.Y.Z` и убедитесь, что GitHub Actions успешно собрал и опубликовал релиз.

Не публикуйте секретный ключ Supabase `service_role` в клиентском приложении или репозитории. Используйте только публичный anon/publishable key на стороне лаунчера.
