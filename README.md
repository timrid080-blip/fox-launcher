# Fox Launcher

Независимый Minecraft Java Launcher для **Windows 10/11 x64**. Тёмная тема, оранжевый акцент, логотип FoxBro. Не является продуктом Mojang или Microsoft.

## Быстрый старт — готовая Windows-версия

1. Распакуй архив `FoxLauncher-Windows.zip` **целиком**, не запускай прямо из ZIP.
2. Запусти `FoxLauncher-Portable-1.0.0.exe`. Установка Node.js не нужна.
3. Открой **Аккаунты** → добавь свой ник для офлайн-игры либо войди через Microsoft.
4. **Мои сборки → Создать сборку**: выбери Minecraft и загрузчик. Для модов нужен **Fabric** или **Quilt**, а не Vanilla.
5. Выбери сборку снизу и нажми **Играть**. При первом запуске нужен интернет: клиент, библиотеки, ресурсы и подходящая Java загружаются автоматически. Это может занять несколько минут.

Программа не подписана сертификатом издателя: Windows может показать SmartScreen «неизвестный издатель». Проверь происхождение файла и его SHA-256 перед запуском; не отключай защиту Windows. Это ранняя сборка, поэтому сначала проверь её на своей Windows-машине.

## Собрать свою сборку и передать друзьям

1. Создай отдельную сборку, например **Minecraft 1.21.1 + Fabric**.
2. В **Моды и ресурсы** выбери эту сборку. Устанавливай моды из **Modrinth**. Версии каталога фильтруются по Minecraft и загрузчику; обязательные зависимости-проекты скачиваются вместе с модом.
3. При необходимости добавь свои `.jar`, ресурспаки и конфиги через **Файлы сборки**. Не ставь одновременно Fabric-, Quilt- и Forge-моды в одну сборку.
4. Запусти игру у себя и проверь совместимость. Закрой игру перед экспортом.
5. **Мои сборки → Экспорт для друзей → Сохранить .foxpack**.
6. Передай друзьям **Windows-лаунчер и свой `.foxpack`**. Они запускают лаунчер → **Импорт** → выбирают файл → добавляют **свой** аккаунт → **Играть**.

Экспортируются: `mods`, `config`, `defaultconfigs`, `resourcepacks`, `shaderpacks`, `kubejs`, `scripts`, параметры игры и `servers.dat`, если они есть. Миры `saves` — только по отдельной галочке. При выборе соответствующей галочки в сборку включается твоя лента новостей.

Не экспортируются аккаунты лаунчера, токены Microsoft, пароль админки, логи, скриншоты, Java и файлы самого клиента Minecraft. **Проверь содержимое конфигов модов перед отправкой:** отдельные моды могут хранить там личные данные. Распространяй только файлы, лицензии которых это разрешают. Моды являются исполняемым кодом — импортируй сборки только из доверенных источников.

Ограничения формата: архив до 512 МБ, распакованные файлы до 1 ГБ и примерно 20 000 файлов. Защита от путей `../`, абсолютных путей, ссылок и недопустимых Windows-имён. Импорт создаёт новую сборку, не перезаписывая существующую.

## Играть с друзьями

Одинаковая сборка сама по себе **не создаёт сервер**. Подключайтесь к одному совместимому Minecraft-серверу или откройте мир в LAN; для LAN через интернет понадобится отдельное сетевое решение/VPN.

- Версии Minecraft и обязательные серверные моды должны совпадать.
- Чисто клиентские моды обычно не нужны на сервере; многие клиентские моды нельзя копировать на dedicated server.
- Офлайн-аккаунт не даёт лицензию. Он подходит для одиночной игры и серверов, чьи правила допускают такие аккаунты; серверы с Microsoft-аутентификацией требуют лицензированный вход.
- Смена ника офлайн-аккаунта меняет UUID и может выглядеть для сервера как новый игрок.

## Свои новости и админ-панель

В боковом меню есть **Админ-панель**. Начальный пароль передан владельцу отдельно в чате, в этом архиве его открытым текстом нет. В панели можно сменить пароль, создавать, редактировать, удалять и закреплять новости.

**Важно:** это локальный редактор новостей, не серверная админка. Банить игроков и управлять чужими Microsoft-аккаунтами он не может. Каждый пользователь запускает свою отдельную копию. Пароль не является защитой от владельца компьютера, который может редактировать локальные файлы.

### Передача новостей без сервера

1. В панели нажми **Новая новость**, введи заголовок и текст, при желании укажи публичную HTTPS-обложку.
2. Нажми **Опубликовать локально** — новость сразу появится у тебя.
3. Нажми **Экспорт ленты** и сохрани файл с именем **`fox-news.json`**.
4. Передай этот файл друзьям. Они могут положить его **рядом с portable EXE** и перезапустить лаунчер либо нажать **Новости → Импорт ленты**.

Альтернативно включи новости в экспорт `.foxpack`. После изменения новостей нужно повторно передать файл или сборку. Переданные ранее файлы сами не меняются.

### Автообновления без собственного backend

Размести экспортированный JSON по публичной HTTPS-ссылке (например, GitHub Pages) и укажи её у всех в **Настройки → Своя лента новостей**. Затем достаточно заменять файл по этой ссылке и нажимать **Обновить** в лаунчере. При недоступности сети используется последний сохранённый кэш этой ссылки. HTML и скрипты в своих новостях не исполняются.

В архиве есть начальный `fox-news.json` с инструкцией. Его можно заменить своей экспортированной лентой перед отправкой друзьям.

### Пароль

Хранится scrypt-хеш с солью в `%APPDATA%\.foxlauncher\admin.json`. Сессия — 15 минут, после 5 неверных попыток — пауза 30 секунд. Рекомендуется сменить начальный пароль. Если забыл пароль, закрой лаунчер и удали **только** `admin.json`: при следующем входе восстановится начальный пароль именно этой сборки. Новости при этом остаются.

## Скины

Пиксельное рисование на UV-карте и 3D-модели, заливка, ластик, пипетка, симметрия, отмена/повтор, Classic/Slim, основной/верхний слой. Есть загрузка PNG 64×64 и старого 64×32, поиск скина по лицензионному нику, экспорт PNG.

- Лицензионному аккаунту скин загружается через Minecraft Services после входа Microsoft.
- Для офлайн-аккаунта скин сохраняется локально и копируется в каталог `CustomSkinLoader/LocalSkin/skins`. Чтобы он появился в игре, нужен совместимый **CustomSkinLoader** с включённым источником LocalSkin.
- Локальный PNG **не отправляется друзьям автоматически**. Видимость скинов у остальных зависит от используемого мода/сервера и его настроек.

## Java и версии

Список версий берётся из официального манифеста Mojang: релизы, снапшоты, old_beta и old_alpha, которые Mojang публикует в этом манифесте. Это не архив абсолютно всех когда-либо существовавших версий.

Java подбирается по метаданным версии; для старых версий по умолчанию используется Java 8. Если совместимой 64-битной Java нет, загружается Temurin из Adoptium с проверкой SHA-256. Игра и моды проверяются по доступным контрольным суммам. Вручную выбранная несовместимая Java выдаст ошибку с просьбой включить автоматический подбор.

Поддерживаются **Vanilla, Fabric, Quilt**. **Forge и NeoForge не реализованы. CurseForge не используется.** Не все снапшоты и старые версии поддерживают Fabric/Quilt. Не любые моды совместимы друг с другом, даже если версия Minecraft совпадает.

## Вход Microsoft

Реализована цепочка Microsoft → Xbox Live → XSTS → Minecraft Services. Пароли Microsoft не хранятся в лаунчере. На Windows токены шифруются Electron safeStorage/DPAPI, если оно доступно.

В этой версии используется публичный client ID официального лаунчера, так как собственный ID не предоставлен. **Полный лицензионный вход на реальном аккаунте в ходе сборки не проверялся; Microsoft может отказать в авторизации этому приложению.** Для надёжного публичного распространения понадобится собственная одобренная Microsoft/Minecraft OAuth-регистрация и замена параметров в `core/auth.js`. Наличие кнопки не гарантирует допуск со стороны Microsoft. Офлайн-режим от этого не зависит.

## Где лежат данные

`%APPDATA%\.foxlauncher`

- `instances\<id>` — отдельные папки игры;
- `versions`, `libraries`, `assets` — общие загруженные файлы;
- `runtime` — Java;
- `skins` — локальные скины;
- `settings.json`, `instances.json`, `accounts.json` — состояние лаунчера;
- `community-news.json` — твои публикации; `imported-news.json` — импортированная лента.

Не отправляй друзьям всю папку `%APPDATA%\.foxlauncher`: в ней есть твои аккаунты. Используй экспорт сборки.

## Запуск из исходников / сборка EXE

Установи **Node.js 22 LTS или новее**. В папке проекта:

```bat
npm ci
npm start
```

Сборка на Windows (portable EXE и установщик):

```bat
npm run dist
```

Результаты находятся в `dist`. Для сборки установщика из Linux нужен Wine. Portable можно собрать отдельно:

```sh
npm run dist:portable
```

В источниках есть GitHub Actions workflow `.github/workflows/build-windows.yml`, который собирает обе Windows-версии на Windows runner. Обновляй Electron и остальные зависимости перед публичным релизом. Для доверенного распространения рекомендуется подпись издателя.

## Что проверено

- Автотесты хеширования пароля/сессий/блокировки, новостей, путей/ссылок, экспорта/импорта и контрольных сумм.
- Интерфейс в Chromium с настоящими методами главного процесса и заменой только Electron-окна/диалогов: создание сборки, установка Sodium с Modrinth, редактор скина, файлы, новости, экспорт и повторный импорт сборки. Проверен минимальный размер 1000×640.
- Запуск Java-процесса для Fabric 1.21.1, Vanilla 1.12.2 и Beta 1.7.3 в Linux-среде. В ней нет игрового дисплея: это smoke-тест установки и старта, **не подтверждение игры до главного меню на Windows**.
- Лицензионный вход и реальное сетевое подключение к Minecraft-серверу не проверялись.

Тесты исходников: `npm test`.
