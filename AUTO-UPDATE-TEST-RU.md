# Автообновление Fox Launcher 3.0.1 — тестирование

## Что уже предусмотрено

- Установочная Windows-версия NSIS использует `electron-updater`: проверяет GitHub Releases или настроенный HTTPS generic feed, автоматически скачивает обновление и предлагает установить его из настроек.
- Проверка запускается при старте и затем раз в час. В настройках отображается состояние и прогресс скачивания.
- Переносная версия Portable не может безопасно заменить сам запущенный EXE через тот же механизм NSIS; для неё показывается ссылка на релиз, а EXE нужно заменить после закрытия программы.
- Обновление не должно удалять пользовательские сборки: данные хранятся отдельно в `%APPDATA%\.foxlauncher`.

## Как проверить GitHub-обновление

1. Собрать и установить NSIS-версию Fox Launcher. Не использовать Portable для теста автоустановки.
2. Убедиться, что текущая установленная версия ниже тестовой.
3. Опубликовать новый GitHub Release с новым тегом `vX.Y.Z` и файлами, созданными electron-builder: установщик NSIS, `latest.yml` и соответствующие `.blockmap`. Репозиторий должен совпадать с настройками GitHub в `fox-services.json`.
4. Запустить установленный лаунчер и открыть **Настройки → Обновления лаунчера**. Можно нажать «Проверить».
5. Дождаться статуса скачивания, затем «Обновление … загружено» и нажать «Установить». Перед установкой нужно закрыть Minecraft.
6. После перезапуска проверить версию и убедиться, что сборки и настройки сохранились.

## Важно

- Обычный push в `main` не выпускает обновление для пользователей: workflow публикует релиз при push тега `v*`.
- Не тестируй установку на единственной рабочей копии: используй тестовую машину/папку и сохрани важные данные.
- Если GitHub медленный в регионе пользователя, автообновление может скачать файл медленно. Для ускорения позже нужно развернуть HTTPS generic feed/CDN с `latest.yml`, установщиком и blockmap; сам код не создаёт хранилище и не загружает туда файлы автоматически.
- Автообновление не проверено реальным опубликованным релизом в этой среде: для этого нужны готовые артефакты и установленная Windows-сборка.
