# Исправление автообновления Fox Launcher

В `package.json` задано явное имя NSIS-установщика:
`Fox-Launcher-Setup-${version}.${ext}`.

Это должно совпасть с URL, который запрашивал старый лаунчер. `electron-builder` сформирует `latest.yml` с именем созданного установщика; workflow уже загружает `latest.yml` вместе с EXE в GitHub Release.

Важно: этот архив содержит исходники. Чтобы исправление попало пользователям, соберите и опубликуйте новую версию через GitHub Actions. Существующий опубликованный релиз сам по себе не изменится.
