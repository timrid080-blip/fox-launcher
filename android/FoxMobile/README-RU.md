# Fox Mobile (Android)

Отдельный Android-клиент для управления Fox ID. Он **не запускает Minecraft**. UI использует тот же Supabase project и публичный publishable key, что и Windows-клиент. В APK нельзя помещать `service_role` или другие секреты.

## Сборка на GitHub

**Android-клиент — отдельный модуль, Windows-сборку он не заменяет.** Рекомендуется загрузить весь проект из архива в тот же репозиторий Fox Launcher, сохранив каталог `android/FoxMobile`. Не загружайте только содержимое Android-папки поверх корня Windows-проекта: это может затереть файлы лаунчера.

1. Отправьте изменения в GitHub в обычный `main`/рабочий branch.
2. В корневом `.github/workflows/android-mobile.yml` настроен отдельный workflow, который запускается при изменениях в `android/FoxMobile/**` или вручную.
3. Откройте Actions → **Build Fox Mobile APK** и дождитесь зелёного статуса.
4. Скачайте артефакт `FoxMobile-debug-apk`. Это debug APK для тестирования, не подписанный релиз.

Workflow Windows запускается отдельно и собирает Windows-лаунчер; Android workflow собирает только APK. Они могут находиться в одном GitHub-репозитории и не мешают друг другу.

Локальная сборка: Android Studio/Gradle, JDK 17, Gradle 8.9, команда `gradle assembleDebug` из этого каталога.

## Возможности текущего прототипа

- вход и регистрация Fox ID через Supabase Auth;
- чтение состояния аккаунта через RPC `fox_action`;
- ручное и периодическое обновление состояния (30 секунд);
- отправка запроса на пополнение в поддержку без автоматического изменения баланса;
- создание обращения поддержки;
- отправка заявки в друзья.

## Важные ограничения

Это первый мобильный клиент для проверки подключения. Названия полей состояния и RPC основаны на существующем backend; если ответ конкретной версии схемы отличается, отдельные карточки могут показать пустые данные или сервер вернёт ошибку. Приложение не обходит RLS/права и не может само начислять баланс. Чат, WebRTC-звонки, загрузка/применение скина и push-уведомления здесь ещё не реализованы. Скин Minecraft не применяется одним лишь сохранением PNG в Android-приложении.

Перед публичным релизом следует проверить сценарии на тестовом аккаунте, добавить экран подтверждения email/восстановления пароля, безопасное обновление/хранение сессии и подписать release APK. Не добавляйте секретные ключи в HTML или репозиторий.
