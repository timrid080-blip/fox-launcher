# Fox Launcher 3.0.1 — изменения исходников

- Добавлен выбор Forge в интерфейсе и валидации сборок.
- Добавлена установка Forge через официальный Maven-репозиторий с проверкой SHA-1, если репозиторий предоставляет checksum.
- Импорт Modrinth `.mrpack` распознаёт Forge-зависимость.
- Добавлена проверка известных конфликтов модов перед запуском и в меню действий сборки.
- Добавлен импорт OptiFine JAR в `mods` для сборок Forge, с проверкой версии Minecraft по имени файла и предупреждением о совместимости.
- Добавлена настройка HTTPS CDN для обновлений; portable использует `latest.json`, NSIS — generic feed `latest.yml`.
- Версия пакета поднята до 3.0.1.

## Ограничения, которые нельзя скрывать

- Проверка конфликтов — эвристическая и не заменяет анализ всех `fabric.mod.json`, `mods.toml`, `neoforge.mods.toml` и зависимостей конкретных модов.
- OptiFine поддерживается как выбранный пользователем JAR для Forge. Автоматического каталога всех релизов OptiFine нет; проверка версии по имени файла не гарантирует совместимость конкретной сборки.
- Forge/OptiFine не были протестированы запуском Minecraft в этой среде.
- Для CDN нужно настроить внешний HTTPS-хостинг и загрузить артефакты; этого невозможно сделать без доступа к аккаунту хостинга.
- Полный регрессионный прогон требует установки зависимостей проекта. Если зависимости отсутствуют, это отмечается отдельно, а не выдаётся за успешный тест.
