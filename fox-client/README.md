# Fox Client

Отдельный клиентский мод Fox Launcher. Текущая цель сборки: **Minecraft Java 1.21.4, Fabric, Java 21**.

## Уже реализовано в исходниках
- **F7** — включает/выключает HUD с координатами XYZ игрока; состояние сохраняется локально.
- **F8** — временно увеличивает FOV на 20 (максимум 110), повторное нажатие возвращает сохранённое значение.
- **F9** — циклически переключает локальные 3D-аксессуары.
- **F10** — открывает собственный гардероб Fox: плащ, тыквенный шлем, крылья, капюшон, корона, рюкзак и нимб.
- **Right Shift** — переключает флаг подсказок интерфейса.
- Настройки F7 и выбранная косметика сохраняются в `config/foxclient.properties`.
- Косметика рисуется как дополнительная геометрия модели игрока с текстурой, а не как иконка интерфейса.

## Важно о текущем этапе
3D-косметика пока отображается **только на собственном персонаже**. Гардероб и модели Fox написаны отдельно; закрытые исходники и текстуры Millida не копируются. Синхронизация с другими игроками требует отдельного безопасного протокола и сервера. Голосовой чат, отображение Fox в TAB/над никами и смена аккаунтного скина пока не реализованы; не собираем пароли или токены Microsoft/Minecraft.

## Сборка и проверка
Нужны JDK 21 и Gradle 8.12. Из этой папки:
```sh
gradle build --no-daemon
```
GitHub Actions автоматически запускает сборку и публикует JAR как artifact. До успешного результата CI и проверки запуска в Minecraft мод нельзя считать полностью проверенным.

## Совместимость
Пока поддерживается только Fabric для Minecraft 1.21.4. Forge/NeoForge и другие версии Minecraft требуют отдельных адаптаций и сборок; один JAR нельзя считать совместимым с Minecraft 1.12—26.x без проверки.
