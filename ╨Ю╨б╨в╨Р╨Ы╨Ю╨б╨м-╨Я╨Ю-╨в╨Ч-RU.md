# Fox Launcher — остаток ТЗ перед выпуском

Статусы ниже относятся к исходникам архива, а не к уже проверенному EXE. Функция считается готовой только после проверки в собранном приложении и подключённом Supabase.

## Сделано в этом патче
- [x] Интерфейс исходящего звонка другу и входящего звонка.
- [x] WebRTC для голоса/видео, принятие и завершение звонка.
- [x] Сигнализация SDP/ICE через Supabase RPC с проверкой, что звонящие — друзья.
- [x] Проверка PNG-скина: целостность заголовка и размер 64×64 или 64×32.
- [x] Для лицензированного Microsoft-аккаунта — загрузка скина в Minecraft Services; локальный PNG сохраняется только после успешной загрузки.
- [x] Для офлайн-аккаунта — сохранение PNG и копирование в каталог CustomSkinLoader при запуске игры.

## Нужно сделать обязательно
- [ ] Применить `backend/migrate-2.2.sql` в существующем Supabase **после** `migrate-2.1.sql`; перед этим сделать резервную копию.
- [ ] Проверить два реальных Fox ID: исходящий вызов, входящий вызов, принятие, отказ, завершение и повторный звонок.
- [ ] Проверить звонок в разных сетях. Если прямое WebRTC-соединение блокируется NAT/роутером, настроить TURN-сервер; одних STUN-серверов не всегда достаточно.
- [ ] Собрать Windows EXE и проверить разрешения микрофона/камеры в Windows.
- [ ] Проверить лицензированный скин на Minecraft-аккаунте и подтвердить его появление в игре.
- [ ] Для офлайн-скинов установить и настроить совместимый CustomSkinLoader. Без такого мода офлайн-скин не может быть показан обычным Minecraft другим игрокам.
- [ ] Проверить возврат скина после перезапуска лаунчера и игры.
- [ ] Проверить обновление с предыдущей версии и имя файла на GitHub Releases.

## Остаток исходного ТЗ
- [ ] Чат друзей: автообновление без ручного нажатия, история, статусы прочтения и уведомления.
- [ ] Промокоды: окончательный пересчёт скидки на сервере и защита от подмены цены клиентом.
- [ ] Авторские коды: комиссия только после подтверждённой покупки, защита от повторного начисления и история начислений.
- [ ] Достижения: проверить всплывающие уведомления, звуки и ограничения фоновой активности.
- [ ] Кошелёк: полный тест подтверждения пополнения и обновления баланса; пока пополнение остаётся запросом в поддержку, не реальным платежом.
- [ ] Поддержка: аудит сценариев создания обращения, ответа, закрытия и прав сотрудника.
- [ ] Проверить все основные разделы: сборки/версии Minecraft, аккаунты, настройки, магазин, задания, достижения, уведомления и запуск игры.
- [ ] Отдельно собрать и протестировать Android APK, если мобильное приложение входит в этот выпуск. Этот патч звонков относится к Windows/Electron-клиенту.

## Не менять без отдельного запроса
- [x] Подписки и права сотрудников/владельца остаются без изменений.
- [x] Реальные платежи не включать: текущий процесс пополнения — запрос через поддержку.

## Ограничения текущей реализации звонков
- Медиа идёт напрямую через WebRTC; Supabase хранит только сигнализацию, не аудио/видео.
- В текущем патче есть STUN, но нет собственного TURN-сервера.
- Требуется миграция базы и проверка двух одновременно запущенных клиентов. До этой проверки звонки нельзя объявлять полностью готовыми к релизу.
