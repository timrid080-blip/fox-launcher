# Fox Launcher 4.0.2 — исправления

- Выдача рублей владельцем зачисляет средства в существующий платёжный баланс `paid_kopeks`: 1 ₽ = 100 копеек. История операций сохраняет точную сумму в копейках.
- Список пользователей в панели управления показывает баланс именно этого кошелька.
- Галочка подтверждённого владельца показывается только профилям с ролью `owner`; права текущего просматривающего больше не добавляют галочку всем игрокам.
- Toast-уведомления возвращены в правый нижний угол, в том числе на узких экранах.
- Открытие модального окна больше не удаляет уже показанные уведомления.

## Обновление Supabase

Перед использованием выдачи рублей выполните в Supabase SQL Editor файл `backend/migrate-2.7-paid-kopeks-admin.sql` после предыдущих миграций Fox Launcher. Миграция не переносит старый баланс `rubles` автоматически и не меняет историю старых операций.

## Проверка

Добавлены регрессионные тесты на маршрутизацию выдачи в `paid_kopeks`, галочку владельца и позицию уведомлений. Сборку Windows нужно дождаться в GitHub Actions перед распространением установщика.
