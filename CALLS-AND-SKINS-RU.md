# Звонки и скины — установка и проверка

## Звонки
1. Сделай резервную копию Supabase.
2. Убедись, что миграции Fox Club до `migrate-2.1.sql` уже применены.
3. Выполни `backend/migrate-2.2.sql` в Supabase SQL Editor.
4. Собери и запусти лаунчер на двух компьютерах с разными Fox ID, которые добавлены друг к другу в друзья.
5. Проверь микрофон/камеру, входящий звонок, принятие, отклонение, завершение и повторный вызов.

Если вызов не соединяется между разными сетями, может понадобиться TURN-сервер. Текущая конфигурация использует STUN и не гарантирует обход всех NAT/фаерволов.

## Скины
- Microsoft-аккаунт: выбрать скин, выбрать лицензированный аккаунт, нажать «Применить». Лаунчер отправляет скин в Minecraft Services; при ошибке API показывает ошибку вместо сообщения об успехе.
- Офлайн-аккаунт: PNG сохраняется локально и при запуске копируется в `CustomSkinLoader/LocalSkin/skins`. Для отображения необходим совместимый мод CustomSkinLoader.
- Поддерживаются PNG 64×64 и 64×32.

## Безопасность
В приложение нельзя помещать Supabase `service_role` key. Сигнализация использует пользовательскую сессию Fox ID и проверку дружбы на стороне SQL RPC.
