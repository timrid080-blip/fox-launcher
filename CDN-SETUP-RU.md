# Fox Launcher 3.0.1 — отдельный источник установщиков и обновлений

Лаунчер не загружает большие EXE, логи или изображения в Supabase. Supabase остаётся для данных аккаунтов. Чтобы ускорить загрузки пользователей в РФ, укажи в админке лаунчера HTTPS-адрес собственного CDN/object storage в поле «CDN установщиков и обновлений».

## Portable-обновления

В корне указанного адреса размести `latest.json`:

```json
{
  "version": "3.0.1",
  "url": "https://cdn.example.com/fox-launcher/FoxLauncher-Portable-3.0.1.exe"
}
```

`url` должен вести на EXE конкретного релиза. Не публикуй манифест до окончания загрузки файла на CDN. Желательно дополнительно выдавать SHA-256 и проверять его перед распространением; текущий portable-путь использует HTTPS и корректность версии/URL, но не проверяет SHA-256 манифеста.

## Установочная версия NSIS

Для `electron-updater` generic provider нужен стандартный `latest.yml` от `electron-builder`, а также EXE и `.blockmap`, если он создаётся. Загрузи их в тот же каталог CDN. Не переименовывай файлы после сборки. Адрес каталога задаётся без завершающего `/`.

## Важно

В этом исходном архиве нет доступа к аккаунту CDN и файлы на внешний хостинг не загружены. Пока поле пустое, лаунчер продолжает использовать GitHub. Нельзя обещать ускорение, пока CDN не настроен и не проверен из РФ.
