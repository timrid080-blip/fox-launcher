# Fox Launcher 4.0.1

## Исправления
- При активных технических работах показывается полноэкранная блокировка для обычных игроков; запуск Minecraft дополнительно проверяется в главном процессе.
- Проверка режима выполняется и до входа в Fox ID, чтобы экран технических работ мог появиться сразу при запуске лаунчера.
- Уведомления и ошибки снова отображаются в правом верхнем углу, в том числе когда открыто модальное окно.
- Успешный звук включается при запуске игры, установке модов, сборок и OptiFine.
- Звук нажатия остаётся единым для кнопок; включение обычных глобальных режимов больше не запускает поверх него отдельный длинный звук. Для режима тревоги отдельный сигнал сохранён.
- В панели управления глобальными режимами добавлена кнопка запуска кат-сцены истории Fox Launcher.

## Проверка перед выпуском
- Выполнить `npm ci` и `npm test`.
- Проверить блокировку технических работ на обычном аккаунте и исключение для владельца.
- Проверить звуки и уведомления на Windows.
- Собрать NSIS и Portable, затем проверить обновление на установленной версии.
- Режимы Supabase требуют применённой миграции `backend/migrate-2.6-launcher-modes.sql`.
