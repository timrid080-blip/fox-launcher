# Fox Launcher 4.0.3 — режим тревоги, тикеты и группы

- Режим тревоги оформлен в стиле экрана регистрации Fox ID. Сообщение предупреждает, что лаунчер под угрозой, просит не заходить до объявления отбоя и ведёт в Telegram-канал [@TempoSMP](https://t.me/TempoSMP). Для обычного игрока режим остаётся блокирующим.
- Вернул тест уведомлений в окне, которое открывается значком колокольчика; системные уведомления остаются в правом нижнем углу.
- Добавлены архив тикетов, удаление тикетов только владельцем и очистка старых переписок. Тикет закрывается после двух дней без решения, доступен для обжалования ещё один день, архивируется через минуту после закрытия и удаляется через три дня после закрытия. Прямые и групповые сообщения удаляются через три дня.
- Добавлены создание групп друзей, добавление друзей, групповой чат и WebRTC-аудио/видеозвонки до 6 участников.
- Добавлены регрессионные тесты для этих функций.

## Обязательные миграции Supabase

Выполни по порядку, если ещё не применены:

1. `backend/migrate-2.8-ticket-archive-cleanup.sql`
2. `backend/migrate-2.9-group-chat.sql`
3. `backend/migrate-3.0-group-calls.sql`

Миграция 2.8 пытается включить автоматическую очистку каждые 30 минут, только если в проекте Supabase уже включён `pg_cron`. Без него очистка запускается при открытии поддержки/групповых чатов; для гарантированного фонового запуска включи pg_cron или настрой Supabase Cron.

Групповые звонки используют STUN и прямое WebRTC-соединение; в некоторых сетях без TURN-сервера связь может не установиться. Windows-сборка и CI должны завершиться успешно перед распространением установщика.
