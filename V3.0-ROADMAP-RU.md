# Fox Launcher 3.0 — план и статус

## Добавлено в этот исходный архив
- Раздел «Инструменты v3» в навигации.
- Предварительная проверка имён JAR на несколько известных конфликтующих пар. Сканер эвристический: он не знает всех метаданных модов и не обещает полную совместимость.
- Локальный анализатор crash report по распространённым шаблонам. Вставленный лог обрабатывается в renderer и не отправляется на сервер.
- Быстрые переходы к папкам `mods`, `shaderpacks`, `resourcepacks` выбранной сборки.
- Информация о текущих ограничениях импорта ссылок и автонастройки Java.

## Ещё требуется реализовать/проверить для полноценной 3.0
- Импорт по URL для Modrinth, CurseForge и GitHub: нужны проверка ссылок, безопасная обработка архивов, метаданные и ограничения на размер. Текущий рабочий путь импорта `.foxpack` сохранён.
- Системный статус профиля (онлайн/АФК/играет) и время последнего входа: требуется согласованная серверная схема Supabase и миграция.
- Серверный мониторинг с пингом/онлайном и картами: нужен источник статуса каждого сервера и явная конфигурация списка.
- Полноценный редактор плащей/пикселей, журнал с галереей скриншотов и статистикой по дням.
- Подтверждённая автонастройка JVM по версии, памяти и процессору. Сейчас базовый выбор памяти/Java уже существует, но он не является AI-оптимизатором.
- Туннелирование локального мультиплеера: не включено; потребуется внешний relay/TURN или сервис туннелирования. Не открывать порты Windows автоматически без отдельного согласия.
- Динамические темы по сборке, отдельный режим слабого ПК и безопасное управление приоритетом процесса. Не отключать сторонние процессы Windows и не «чистить кэш» вслепую.
- Профиль последнего входа, статус АФК и системные уведомления — интегрировать с сервером и тестировать на нескольких клиентах.
- Полный интеграционный тест Windows, Supabase, Minecraft и автообновления; выпускной установщик ещё не создан.

## Важные ограничения текущего инструментария
- Сканер конфликтов использует небольшой встроенный список известных сочетаний. Отсутствие предупреждений не означает, что все моды совместимы.
- Анализ crash report — подсказка по шаблонам, а не AI-диагностика.
- Проверка скинов, звонков, чата и облачных функций на реальных учётных записях в этой среде не выполнялась.
- Архив содержит исходники. Версию 3.0.0 нельзя публиковать как рабочее обновление, пока не собраны и не проверены EXE и файлы `latest.yml`/релиза.


## Android
- Android-клиент исключён из версии 3.0.0: текущая мобильная версия слишком ограничена и не должна позиционироваться как полноценный лаунчер. Возврат мобильного приложения рассматривается для 4.0/5.0 после отдельного проектирования интерфейса и возможностей.
