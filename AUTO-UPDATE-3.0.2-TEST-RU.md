# Проверка автообновления Fox Launcher 3.0.2 → 3.0.3

Эта тестовая исходная версия 3.0.2 настроена на GitHub-репозиторий `timrid080-blip/fox-launcher` и добавляет конфигурацию `electron-builder` для публикации релизов. Это **исходники**, не готовый EXE.

## Сборка версии 3.0.2

В PowerShell в корне проекта:

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run dist:update
```

Ожидаемые файлы находятся в `dist`. Для NSIS должны быть созданы установщик версии 3.0.2, `latest.yml` и, если создан, `.blockmap`.

## Проверка

1. Установи именно NSIS-установщик 3.0.2, а не Portable.
2. Собери следующую версию, изменив `version` в `package.json` и корневой записи `package-lock.json` на `3.0.3`.
3. Создай GitHub Release с тегом `v3.0.3` и прикрепи установщик 3.0.3, `latest.yml` и `.blockmap`, если он есть.
4. Запусти установленный Fox Launcher 3.0.2 и нажми «Проверить обновления» в настройках. Должна появиться загрузка 3.0.3; после скачивания — предложение установить.

Не публикуй тестовый релиз как предварительный (prerelease): проверка игнорирует prerelease. Не забудь, что автоматическая установка проверяется в NSIS-версии; Portable предлагает скачать новый EXE и заменить его вручную.

## Важно

- В `package.json` задан GitHub-репозиторий для генерации метаданных обновления.
- GitHub Release должен быть опубликован и не быть Draft/Prerelease.
- Если `latest.yml` не появился в `dist`, не публикуй релиз: сначала пришли вывод сборки.
- Реальное скачивание/установка не считается проверенным, пока тест 3.0.2 → 3.0.3 не выполнен на Windows.
