# Fox Launcher Android — отложено

В версии 3.0 Android-приложение исключено из поставки, чтобы не выдавать урезанный мобильный клиент за полноценный лаунчер.

Текущая цель Fox Launcher 3.0.0 — Windows-ПК. Android-версию вернём в план на 4.0 или 5.0, когда будет готов полноценный мобильный интерфейс и определены возможности, которые реально доступны на Android. Не переносить ПК-функции напрямую в Android без адаптации.

Из архива удалены `android/FoxMobile` и workflow сборки APK. Это не удаляет APK, уже установленные на устройствах, и не меняет серверную базу данных.
