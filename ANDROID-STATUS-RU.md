# Fox Launcher Android 5.0 — мобильное направление

Android-клиент возвращается в план версии 5.0 как отдельное мобильное приложение, а не копия Electron-интерфейса ПК. Требуется адаптированный экран телефона для регистрации и входа, новостей, модов/сборок, друзей и чатов, звонков, поддержки, заданий/достижений, аккаунтов, настроек и файлов.

Права владельца должны проверяться сервером через Fox ID/Supabase. Наличие скрытого экрана не даёт доступ само по себе. Перед публикацией APK необходимо настроить Supabase URL и publishable key, проверить политики RLS, звонки/WebRTC на реальных устройствах и собрать release APK с подписанием.

Мобильный клиент должен явно показывать функции, доступные на Android. Запуск Java Edition Minecraft из Android не обещается: поддержка игры зависит от устройства и отдельной реализации.
