# Fox Launcher Full — отчёт изменений

## Изменено в исходниках
- В Fox Store добавлено поле промокода, проверка на сервере и отображение скидки на товарах при оплате Фоксами.
- Серверная миграция `backend/migrate-2.3.sql` добавляет проверку промокода и фиксирует его использование в той же транзакции покупки.
- Выдача игровой валюты проверяет игрока, целую сумму и причину до отправки запроса; после выдачи панель обновляется. Причина должна содержать минимум 3 символа.
- Сохранены предыдущие файлы проекта и миграция сигнализации звонков `migrate-2.2.sql`.

## Обязательное действие владельца
1. Сделать резервную копию Supabase.
2. Если `migrate-2.2.sql` ещё не применялась, применить её первой.
3. Затем выполнить `backend/migrate-2.3.sql` в Supabase SQL Editor. Не запускай миграцию 2.3 поверх старой базы без проверки последовательности.

## Ограничения проверки
JavaScript-синтаксис и целостность ZIP проверяются отдельно. Реальный Supabase не подключён к этой среде; миграция не применена к пользовательской базе, EXE не собран. Авторская комиссия и промокоды при оплате рублями не подключены.
