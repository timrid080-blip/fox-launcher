# Fox Launcher 1.7.0 — изменения для игроков

- Новости и уведомления обновляются автоматически, без ручного обновления страницы.
- Добавлена настройка запуска Fox Launcher вместе с Windows.
- В настройках можно выбрать основной цвет интерфейса; кнопка «Играть» использует выбранный цвет.
- Возвращена оранжевая тема по умолчанию.
- Исправлена обработка старого значения цвета, которое ошибочно задавало голубую тему по умолчанию.

> Это описание включает только изменения интерфейса для игроков. Остальные функции релиза публикуются после реализации и проверки.
