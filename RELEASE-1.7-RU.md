# Fox Launcher 1.7.0

## Что нового для игроков
- Новости и объявления обновляются автоматически, без ручного нажатия «Обновить».
- Уведомления Fox Club периодически проверяются в фоне.
- В настройках появился параметр запуска лаунчера вместе с компьютером.
- Новый голубой цвет по умолчанию для создаваемых сборок.
- В профилях учитываются существующие дружеские связи и исходящие заявки, чтобы не предлагать повторное добавление.

## Важно
- Платёжная система не обходится: выдача настоящих рублей должна выполняться только серверной административной операцией с журналированием. Старые учётные рубли не являются деньгами.
- Для серверных функций Fox Club применяй только проверенные миграции к своей базе Supabase; интерфейс сам по себе не меняет серверные права.
